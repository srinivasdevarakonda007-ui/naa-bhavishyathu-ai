# Naa Bhavishyathu AI

AI Dream Profession Portrait Studio — Telugu-first MVP.

## MVP flow
Photo upload → profession selection → portrait frame → Telugu inspirational story → future HD/print/share flow.

## Current status
Frontend MVP implemented. AI generation is intentionally not faked; secure server-side image generation and payment integration are the next milestones.

## Planned production architecture
- Mobile-first web/PWA
- Server-side AI image generation (API key never exposed in browser)
- Telugu story generation
- Print-ready A4/A3 export
- WhatsApp sharing
- Razorpay checkout after quality validation
- Photo retention/deletion controls and AI-generated disclosure
